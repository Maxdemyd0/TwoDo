Legacy project

TwoDo

Documentation for the original standalone TwoDo project. This repository is preserved as a public, source-available look at the project before TwoDo evolved into the Orbis platform.

Overview

TwoDo began as a focused task-management project built around simple lists, quick task entry, and a lightweight interface. The legacy version is preserved for reference, learning, history, and approved contributions.

This documentation describes the legacy standalone project. Current TwoDo development belongs to Orbis.

Project status

Legacy

The standalone project is no longer the primary TwoDo product.

Source available

The code may be viewed publicly, subject to the repository license.

Preserved

The repository remains useful as project history and technical reference.

Core features

The exact feature set depends on the final legacy snapshot, but the project centers on:

  • task creation and management
  • task lists and organization
  • completion state
  • simple productivity-focused workflows
  • a lightweight standalone user interface
